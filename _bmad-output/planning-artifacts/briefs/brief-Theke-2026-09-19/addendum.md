# Addendum: Theke

## Base técnica existente

Este contenido sirve como entrada para el futuro PRD y la arquitectura; no representa por sí solo compromisos de producto.

- Theke es actualmente un prototipo frontend web construido con React, TypeScript, React Flow, Zustand y Tailwind CSS.
- La superficie funcional principal es un canvas de grafo con nodos de texto, multimedia, audio, documentos, enlaces, figuras y contenedores.
- El estado actual utiliza datos demostrativos y memoria de sesión; todavía no hay backend, autenticación, persistencia, colaboración ni carga real de archivos.
- Las reglas operativas verificadas del canvas se mantienen en `AGENTS.md` y deben preservarse durante la evolución del prototipo.

## Capacidades futuras mencionadas por el creador

- Más gramáticas de diagrama, comenzando por una línea de tiempo interactiva.
- Componentes derivados de dos o más recursos, como resúmenes, comparaciones o síntesis.
- Una plataforma pública más avanzada para descubrir diagramas, más allá del enlace compartido básico.
- Coedición opcional para diagramas cuyos autores habiliten colaboración.

## Preguntas para etapas posteriores

- Qué propiedades editables se sincronizan globalmente en cada tipo de recurso y cuáles pertenecen a su aparición dentro de un diagrama.
- Qué otros públicos y disciplinas muestran suficiente afinidad con el caso inicial de estudio.
- Qué propuestas de pago, además del uso ampliado de IA, demuestran valor real para los usuarios.
- Qué componentes derivados aportan comprensión sin reemplazar el trabajo intelectual del usuario.

## Permisos detallados del compartido

- La composición y las posiciones de los nodos permanecen bajo control del autor.
- Cada visitante puede crear y editar sus propios comentarios.
- El autor puede consultar los comentarios en contexto o como lista y eliminarlos para moderar el compartido.
- El autor no puede modificar el contenido escrito por otra persona.
- Los comentarios no se convierten automáticamente en recursos, relaciones ni conocimiento global.
